# 首页（画廊感首页）调参手册

所有可视觉调整的值都在 **`web/src/features/gallery-home/gallery-home.css`** 这一个文件里（作用域 `.ghome`，不会污染后台）。
改完保存即可，dev（3001）会热更新。本文每个条目都标了 **选择器 + 当前值 + 怎么调**。

> 调参总原则：
> - **字号 / 行高 / 间距**：直接改对应选择器里的 `font-size` / `line-height` / `margin` / `padding`。
> - **颜色**：优先改 `.ghome` 顶部的「语义令牌」（`--gh-*` / `--agent-panel-*`），一处改全站生效；不要散改各处硬编码色。
> - **字体**：全站走系统黑体栈（`--font-sans` / `--font-serif`），不加载任何商业/网页字体。

## 8. 滚动出现动画（scroll-reveal）

元素**滚动进入视口时**才出现：透明 + 下沉 + 轻微模糊 → 清晰归位。逻辑在 `index.tsx` 的一个 IntersectionObserver effect（`threshold 0.1`、底部 `rootMargin -8%`），进入视口加 `.in` 类触发，触发后立即 unobserve 防重复。

### 8.1 两种挂法

| 属性 | 作用 | 用在哪 |
|---|---|---|
| `data-reveal` | 单个元素自己动，可配 `data-reveal-delay="毫秒"` 控制起播延迟 | Featured video、画廊 lead 段、Explore 链接、模型滚动条 |
| `data-reveal-group` | 盒子级：**内部直接子元素**自动逐个挂动画，按 `data-reveal-step="毫秒"`（默认 110，最多累积 8 步）依次错峰 | section-head / agent-head / agent-composer / agent-chips / agent-features / agent-preview / studios / gallery-grid / model-stats / model-list / cta-inner / cta-features / home-closing-inner |

**嵌套规则**：子元素若自己也带 `data-reveal` 或 `data-reveal-group` 会被跳过（交给它自己处理），避免父子上浮动效叠加。所以 `.agent-preview` 里再给 `.agent-preview-plan` / `.agent-preview-steps` 加 group，列表项就各自单独出现。

### 8.2 四个调参值（gallery-home.css 末尾 `.ghome` 块，改一处全站生效）

| 变量 | 当前值 | 作用 |
|---|---|---|
| `--reveal-dur` | `1.05s` | 单元素动画时长，**越大越慢** |
| `--reveal-y` | `38px` | 起始下沉距离，**越大越明显** |
| `--reveal-blur` | `8px` | 起始模糊，越大越"浮现" |
| `--reveal-scale` | `0.972` | 起始缩放，**越小越明显** |
| `--reveal-ease` | `cubic-bezier(0.16,1,0.3,1)` | 缓动曲线 |

### 8.3 逐元素错峰档位（当前值，直接改数字）

- **Agent 区**：agent-head `90` / agent-composer `110` / agent-chips `55` / agent-features `120` / agent-preview `100` / 预览卡内 plan 与 steps 各 `90`
- **Studio / 画廊**：section-head `90` / studios `150` / gallery-head `90` / gallery-grid `95`
- **模型 / 收尾**：model section-head `90` / model-stats `140` / model-list `85` / cta-inner `110` / cta-features `70` / home-closing-inner `120`

### 8.4 Hero 首屏（不走 IO，直接入场）

Hero 用 `.rise` 类 + 内联 `animation-delay` 递进（0 / 80 / 160 / 240 / 320 / 420ms），动画 `home-rise 1s`。
- 放慢：改 `.ghome .rise` 的 `1s`
- 加大幅度：改 `@keyframes home-rise` 的 `translateY(30px)` 与 `blur(7px)`

### 8.5 兜底与性能

- 系统「减少动效」(`prefers-reduced-motion`) 时全部关掉，元素直接可见。
- 无 IntersectionObserver 的极老浏览器：`.ghome` 加 `.no-io` 类，元素直接显示，不会被藏住。
- `will-change` 只在「未出现」时生效（`:not(.in)`），出现后释放，避免几十个元素长期占合成层。
- 只动 `opacity / transform / filter`，卡片自身的 hover 过渡（Studio 上移、画廊卡上移、模型行右移）全部保留。

### 11.16 05 接入卡右侧视觉：接入流程演示（第 18 轮）

原来卡右侧是 4 个图标胶囊（终端 / 星光 / 箭头 / 虚线空块），纯装饰、和开发者主题不搭。现改成三步小流程，9 秒一轮循环：

| 步骤 | 内容 | 动效 |
| --- | --- | --- |
| ① 命令行 | `> ymm connect`，深色终端底 + 金色提示符 | 12% 时淡入上浮，光标 1.05s 闪烁 |
| ② 接入成功 | `✓ connected`，金色对勾胶囊 | 33% 时淡入 |
| ③ 生成图片 | 缩略图 + 右下 `image.webp` 标签 | 54% 时淡入，图片从模糊 6px / 1.05 倍收敛到清晰 |

- 结构：`.api-flow` → `.api-flow-cmd` / `.api-flow-ok` / `.api-flow-img`，步骤之间用金色 1px 虚线连接
- 动画：`api-flow-in-1/2/3`（9s 同周期、不同起点）+ `api-flow-caret` + `api-flow-pop`
- 减弱动效（prefers-reduced-motion）时三步直接静态全显
- 换图只改 `index.tsx` 里 `.api-flow-img img` 的 src

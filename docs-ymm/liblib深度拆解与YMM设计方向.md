# liblib.art 深度拆解 × 一幕AI（YMM）设计方向

> 版本 v1.0 · 2026-11-01
> 目标站点：cdymm.com（一幕AI / YMM）
> 目标气质：**大气 · 自由 · 简约 · 年轻潮流**
> 配套资产：`design-system/preview.html`（活原型）、`design-system/tokens.css`（令牌）、`design-system/设计规范.md`

---

## 0. 一页结论（TL;DR）

| # | 结论 | 对我们的意义 |
|---|---|---|
| 1 | liblib 的本质不是"模型站"，而是**"产品地图 + 内容货架"**：顶栏用下拉把 6 条创作路径一次铺开 | 我们要有同等清晰的路径感，但用**更少的入口**表达 |
| 2 | 它的首屏不写功能介绍，而是**把模型排成货架**（一行名字 + 一句能力 + 右下角动作） | "卡片即入口"值得学；但我们的货架应是**作品**而非模型 |
| 3 | 分类按**用途/行业**命名（电商营销、短剧漫剧…），不按技术命名 | 中文站最有效的内容组织法，直接沿用 |
| 4 | 转化动作只有两个：**去使用 / 做同款**，且永远贴在内容上 | 我们必须把"生成同款"做成全局唯一主动作 |
| 5 | 密度极高：促销条 + 会员浮层 + 9 分类 + 双层 tab + 满屏卡 | **这是我们要反向做的部分**：减法换呼吸感 |
| 6 | 视觉语言：浅底、黑主色、方形圆角（8~12px）、单色线性图标、极少阴影 | 与我们的黑白双方案天然同源，可继承骨架 |
| 7 | 动效克制：几乎只有 hover 抬升、骨架屏、数字变化；没有大面积滚动动画 | 我们已有更强的动效层，需**收着用**，只在 3 个位置释放 |
| 8 | 信息可信度靠"作者署名 + 使用数 + 版本号"三件套 | 我们的瀑布流已具备，需补**版本/参数**信息 |
| 9 | 它把"算力/积分"做成显性货币，但用倒计时促销施压 | 我们做**透明计费**，不做焦虑营销 |
| 10 | 差异化机会：**从"工具型货架"转向"策展型画报"** | 这就是 YMM 的设计主线 |

**一句话主张**：保留 liblib 的**能力地图与转化效率**，剥离它的**密度与促销噪音**，用"编辑式画报"的排版语言重做一遍——**少一半元素，大一倍呼吸，强一个动作**。

## 2. 信息架构（IA）

### 2.1 三层结构总览

```
L0  品牌层        首页 / 登录注册 / 全局搜索 / 会员入口 / 积分入口
      │
L1  意图层        逛（发现）        做（创作）           管（资产）        学（教程）
      │            ├ 发现灵感        ├ 图片生成           ├ 资产            ├ 经验文章
      │            ├ 图片模型        ├ 视频生成           ├ 创作中心        └ 视频教程
      │            ├ 视频特效        ├ WebUI / ComfyUI    └ 发布
      │            └ 工作流          ├ 训练 LoRA
      │                              └ AI 应用（6000+）
      │
L2  对象层        作品详情 / 模型详情 / 应用详情 / 工作流详情 / 生成任务结果
      │
L3  归属层        作者主页 / 模型作者 / 个人中心 / 会员权益 / 订单与积分
```

**关键洞察**：liblib 的 L1 不是按"功能模块"分的，而是按**用户意图**分的——逛、做、管、学。四条意图共享同一套对象层（作品/模型/应用），所以任何入口最终都落到"某个对象 + 一个动作"。

| 层级 | 页面 | 路径 | 核心任务 | 关键组件 |
|---|---|---|---|---|

| L1 | 视频生成 | `/ai-tool/video-generator` | 多模型视频 | 同上 + 时长/首尾帧 |

## 3. 导航逻辑

### 3.1 顶栏：一个下拉 = 一张产品地图

```
[Logo]  首页   创作 ▾   资产   创作中心   发布   教程   API        [搜索] [积分] [会员] [头像]
                 ├ 图片生成   ← 按"产出物"分
                 ├ 视频生成
                 ├ WebUI      ← 按"使用方式"分
                 ├ ComfyUI
                 ├ 训练 LoRA  ← 按"动手程度"分
                 └ AI 应用
```

**这是全站最聪明的设计**：六项不是并列堆叠，而是**三种分类法叠在一个下拉里**——产出物（图/视频）、操作方式（WebUI/ComfyUI）、动手程度（自己训 / 用别人的）。用户不需要先理解平台架构，只需要回答"我想干什么"。

**代价**：主栏仍有 7 项（首页/创作/资产/创作中心/发布/教程/API），右栏还有 5 个（搜索/积分/会员/邀请/头像），一条顶栏承载 12 个入口，认知负担重。

**YMM 取舍**：学"下拉即地图"的组织智慧，不学它的长度。

### 3.2 二级导航：双层 tab 的内容分流

首页正文顶部是 `图片模型 / 视频特效 / 发现灵感 / 工作流 / 全部`，下面再接九行业分类。
**优点**：一次点击就把"内容形态"和"用途场景"分开，互不干扰。
**问题**：两层都是横排 chip，视觉权重接近，用户会犹豫先点哪层。

**YMM 取舍**：只保留**一层主筛选**（内容形态），行业分类降级到"更多"抽屉或左栏，避免双层 chip 打架。

### 3.3 引导与转化路径

| 环节 | liblib 做法 | 评价 |
|---|---|---|
| 新人 | 登录弹窗直接给 4 条权益 + "立即登录领取" | **优秀**：一句话说清价值，无表单噪音 |
| 内容 → 动作 | 卡片右下角恒定一个动作（去使用 / 做同款） | **优秀**：动作永远贴着内容，不另设 CTA 区 |
| 付费 | 顶部倒计时 + 折扣 + 三档对比 | **有压迫感**，与"自由"气质冲突 |
| 空态 | 资产页空 → 引导去生成 | 常规但有效 |

**YMM 取舍**：保留"权益前置"的登录弹窗与"动作贴内容"，放弃倒计时促销。

## 4. 逐页拆解

### 4.1 首页 `/`

| 维度 | 观察 | 评价 |
|---|---|---|
| 布局 | 通栏促销条 → 顶栏 → Hero（一句话 + 4 权益条）→ 主 tab → 双列模型货架 → 九分类 → 作品墙 → 会员卡 → footer | 首屏信息量极大，**像"仪表盘"而非"门面"** |
| 首屏任务 | 让人相信"模型最多、最新、最便宜" | 有效，但缺少**情感与审美**锚点 |
| 卡片 | 一行模型名 + 一句能力描述 + 右下角动作；两列纵向排列 | **最高效的货架**：不用图，纯文字也能卖 |
| 配色 | 浅灰白底 + 近黑文字 + 少量品牌色点睛 | 中性、工具感强 |
| 卡片层级 | 图卡与视频卡混排、不加分区标题 | 减少割裂，但**牺牲可预期性** |
| 动效 | 几乎无入场动画；hover 仅轻微反馈 | 快、稳，但**没有记忆点** |
| 问题 | 促销条 + 会员浮层 + 登录浮层三层叠加 | 首屏被"卖东西"占满 |

**可借鉴**：① 卡片即入口；② 分类按用途命名；③ 作者署名 + 数据落款。
**要反向做**：首屏必须有**一个情绪高点**（大幅视觉/一句主张），而不是六排货架。

### 4.2 发现灵感 `/inspiration`

| 维度 | 观察 | 评价 |
|---|---|---|
| 布局 | 顶部形态 tab + 分类 chips + 不等高瀑布流 | **最贴合"逛"的心智** |
| 卡片 | 封面为主，落款作者名 + 数字；hover 才出现"做同款" | 干净，但**信息过少**（无参数/模型） |
| 转化 | "做同款"一键复刻参数 | **杀手级动作**，把"看"直接变成"做" |
| 密度 | 4~5 列，卡片间距 ≈12~16px | 信息多，但**拥挤、廉价感** |

**可借鉴**：做同款 + 作者署名 + 瀑布流节奏。
**要改造**：列数降到 3~4，间距拉到 24~28px，卡片**无边框**（我们已落地 v1.6.3）。

### 4.3 模型详情 `/models/*`

| 维度 | 观察 | 评价 |
|---|---|---|
| 布局 | 左：封面 + 版本列表；右：标题 + 作者 + 数据 + 立即生图/下载；下方：示例图（带参数）、触发词、推荐参数、评论 | 信息完备，**决策路径清晰** |
| 关键组件 | 版本切换器、触发词代码块、示例图"抄作业" | 触发词与参数可复制=**降低使用门槛** |
| 问题 | 下载入口路径受限（需实名 + 特定页面） | 体验割裂，但**不是设计问题而是策略问题** |

**YMM 取舍**：**不自建模型库**。我们的详情页是**提示词/作品详情**，但可移植"触发词 + 推荐参数 + 示例图抄作业"三件套——这三样才是真正提升成功率的东西。

### 4.4 图片生成 `/ai-tool/image-generator`

| 维度 | 观察 | 评价 |
|---|---|---|
| 布局 | 左栏（模型选择、提示词/负向、尺寸/步数/种子、参考图上传）+ 右栏画布（结果网格 + 操作）+ 底部"一键生成" | **行业标准三栏**，学习成本最低 |
| 交互 | 生成中骨架/进度；结果支持放大、下载、分享、保存 | 反馈明确 |
| 问题 | 参数项多，新手不知从哪下手 | 需要**分层暴露**（基础/高级） |

**YMM 取舍**：不做表单式生成器。我们的 `/studio/canvas` 是**无限画布**——差异化优势，保持"自由排布"而非"填表"。

### 4.5 AI 应用 / 工作流 `/workflows`、`/lib3`

| 维度 | 观察 | 评价 |
|---|---|---|
| 卡片 | 功能卡（图标 + 名称 + 一句用途），**hover 才浮现"使用"** | 干净，且降低误触 |
| 组织 | 按场景（图像编辑/电商/建筑）分类，6000+ | 规模即壁垒，**我们短期无法对标** |

**YMM 取舍**：P2 再评估。先把"提示词 → 生成"这条主链路做到极致。

### 4.6 资产 `/asset`

| 维度 | 观察 | 评价 |
|---|---|---|
| 布局 | 网格 + 顶部"生成方式 / 生成日期"双维度筛选 + 批量下载/删除 | **克制的工具页**，值得学 |
| 状态 | 空态引导去生成；多选进入批量模式 | 标准但完整 |

**YMM 取舍**：P1 落地"我的作品"，只做两件事：**按时间/类型筛选 + 一键复用到画布**。

### 4.7 会员 / 积分

| 维度 | 观察 | 评价 |
|---|---|---|
| 结构 | 三档价格卡 + 权益清单（并发/存储/去水印/加速）+ 算力换算（1 积分 ≈ ¥0.048 ≈ 70 个视频） | **换算透明**是最大优点 |
| 问题 | 倒计时 + 多档折扣 + 红包叠加 | 焦虑营销，损害"自由"气质 |

**YMM 取舍**：保留"算力换算成人话"，去掉倒计时。

### 4.8 教学 `/teaching/*`

| 维度 | 观察 | 评价 |
|---|---|---|
| 结构 | 列表（封面 + 标题 + 作者/时间）+ 文章页（大标题、正文、图片、footer 矩阵） | 标准内容站，**SEO 友好** |
| 价值 | 教程即长尾流量入口 | 与我们的 SEO 落地页策略一致 |

## 5. 元素级特征库

### 5.1 配色

| 角色 | liblib 观感 | 我们的处理 |
|---|---|---|
| 底 | 近白 / 浅灰（≈ `#F7F7F8`） | `#FFFFFF` + `--card-2:#F4F4F5` |
| 主文字 | 近黑（≈ `#1A1A1A`） | `#18181B`（已有） |
| 强调 | 少量品牌色点睛（按钮/链接） | **单一强调色 + 渐变**，12 套预设可换 |
| 语义 | 红（促销/警告）、金（会员） | 保留语义色，**促销色不入常规界面** |
| 阴影 | 极轻，几乎只用 1px 边框分隔 | 去边框，用**留白 + 极淡阴影**分层 |

### 5.2 字体与排版

- liblib：中文黑体为主，字重 400/500/600，标题 20~28px，正文 13~14px，行高 ≈1.5。
- **问题**：正文 13px + 行高 1.5 在长文与卡片描述中偏紧，中文阅读吃力。

**YMM 规范**（遵循"大气"铁律）：
| 层级 | 字号 | 行高 | 字重 |
|---|---|---|---|
| 页面主标题 | 40~56px（clamp） | 1.05~1.15 | 650~700 |
| 区块标题 | 24~28px | 1.25 | 650 |
| 卡片标题 | 15~16px | 1.45 | 600 |
| 正文 | 14~15px | **1.75** | 400 |
| 辅助文字 | 13px | 1.6 | 400~500 |
| 数字/代码 | 12~13px mono | 1.4 | 500 |

> 中文正文**禁止 12px**；卡片描述最多 2 行，超出省略。

### 5.3 圆角与形状

| 元素 | liblib ≈ | YMM |
|---|---|---|
| 按钮/输入 | 8~10px | **10px**（`--radius`） |
| 卡片 | 10~12px | **14px**（`--radius-lg`） |
| 大容器/抽屉 | 12~16px | **20px**（`--radius-xl`） |
| 头像/色点 | 全圆 | 全圆 |
| 图标容器 | 方形圆角 | 方形圆角（**不用全圆胶囊**，用户已明确） |

### 5.4 图标

- liblib：单色线性图标（1.5~2px 描边），与文字同色，尺寸 16/20。
- YMM：沿用线性单色（lucide 风格），**统一 1.75px 描边**；强调态才上色；禁止彩色拟物图标。

### 5.5 按钮

| 类型 | 规格 |
|---|---|
| 主按钮 | 高 40/44/48；**渐变底**（`--primary-grad`）；hover 抬 2px + 光环 + 流光；active `scale(.98)` |
| 次按钮 | 透明底 + 1px 边；hover 底色 `--card-2` |
| 文字按钮 | 无底无边；hover 变色 + 下划线偏移 |
| 危险操作 | 仅描边，hover 才填充 |

### 5.6 卡片（我们的核心资产）

| 项 | 规格 |
|---|---|
| 边框 | **无**（v1.6.3 已落地）；靠图与留白分层 |
| 封面比例 | 3:4 / 4:5 为主，混入 1:1 与 9:16 制造节奏 |
| 角标 | 左上角**无边框**图标 + 文字（`--ctag`） |
| 信息 | 标题（1 行）+ 作者（头像 18px + 名）+ 👁/♥ 数字 |
| 悬停 | 封面 `scale(1.02)` + 底部**推挤展开**"生成同款"（0fr→1fr） |
| 阴影 | 默认无；hover 一层极淡阴影 + 2px 抬升 |

### 5.7 动效（只在这三处释放）

| 位置 | 动效 | 时长/曲线 |
|---|---|---|
| 首屏 | 极光光斑漂移 + 标题逐行揭示 | 19s 循环 / 480ms 入场，`cubic-bezier(.16,1,.3,1)` |
| 指针 | 190px 光标光晕（颜色跟随 accent） | 跟随 rAF，opacity .45/.72 |
| 列表 | 滚动揭示（IntersectionObserver）+ 数字滚动 | 480ms，逐条 +60ms；数字 900ms |

**明确不做**：滚动视差堆叠、满屏粒子、自动轮播打断阅读、超过 600ms 的装饰动画。

### 5.8 交互反馈

| 场景 | 反馈 |
|---|---|
| 悬停 | 200ms 变色/抬升，绝不改变布局 |
| 点击 | `scale(.98)` + 主按钮流光扫过 |
| 提交 | 按钮内联 loading（不整页遮罩）+ 骨架占位 |
| 成功 | 轻量 toast（2.4s，顶部居中，不遮内容） |
| 失败 | 字段级 inline 错误 + 可重试按钮，**不弹红框大窗** |
| 空态 | 一句说明 + 一个主 CTA + 一个示例入口 |
| 加载 | 骨架屏（与真实布局同构），禁止转圈占满屏 |

## 6. 设计语言总结：liblib 的 8 条规律

1. **货架思维**：任何内容都以"卡 + 名字 + 一句能力 + 一个动作"呈现，可无限复制。
2. **动作贴内容**：转化按钮永远在内容卡上，不设独立 CTA 区。
3. **用途命名**：分类用行业/场景词，不用技术词。
4. **中性底 + 单点色**：界面几乎无色，颜色只用于"可点"和"要付费"。
5. **方形圆角**：统一 8~12px，拒绝胶囊与超大圆角，保持工具感。
6. **低层级**：靠 1px 边框与浅灰底分层，几乎不用阴影。
7. **快反馈**：hover 即变、点击即走，动效只做状态过渡。
8. **密度优先**：一屏尽可能多放，宁可挤也不留白。

> 第 1~7 条是**能力**，第 8 条是**代价**。我们要继承能力，拒绝代价。

## 9. YMM 设计方向

### 9.1 定位一句话

> **一幕AI 不是"模型超市"，是"灵感画报 + 一键开画"。**
> 用户来这里不是查参数，是**看见想做的画面，然后立刻做出来**。

### 9.2 五条设计原则

| 原则 | 含义 | 可检验标准 |
|---|---|---|
| **① 少一半** | 每个页面只保留一个主任务 + 一个次任务 | 首屏可交互元素 ≤ 12 个 |
| **② 大一倍** | 区块间距 ≥ 32px，列表项 ≥ 24px，正文行高 ≥ 1.75 | 任意两区块间不得只靠 1px 线分隔 |
| **③ 一个动作** | 全站唯一主动作："生成同款 / 开画" | 任何内容卡 hover 都必须出现它 |
| **④ 无框分层** | 用留白、色阶、字号对比分层，不靠边框 | 卡片默认 border: none |
| **⑤ 克制的炫** | 动效只在首屏/指针/列表三处；颜色只用一个强调色 | 一屏内彩色元素 ≤ 2 处 |

### 9.3 视觉方向：Quiet Editorial × Neo Tool

- **Quiet Editorial（静奢画报）**：大字号对比、宽留白、serif 与 sans 混排、以图为主角。
- **Neo Tool（新工具感）**：方形圆角、线性图标、精准反馈、无多余装饰。

两者交汇出的气质：**像一本会动的画册，而不是一个后台**。

### 9.4 令牌落地（已具备，需收敛使用）

```
底：#FFFFFF / #09090B（黑白双方案）
文字：#18181B / #FAFAFA
强调：12 套 accent 预设（单色 + 135° 双色渐变 --primary-grad）
圆角：10 / 14 / 20 / 999
间距：4 基数列 → 8/12/16/20/24/32/48/64/96
字号：12 / 13 / 14 / 15 / 18 / 22 / 28 / 36 / 48 / 56
动效：150 / 200 / 320 / 480ms，cubic-bezier(.16,1,.3,1)
```

**收敛规则**：默认只用 `accent-indigo`；渐变只出现在**主按钮**与**首屏极光**；其余元素一律中性色。

### 9.5 版式系统

| 项 | 规格 |
|---|---|
| 栅格 | 12 列，gutter 24px |
| 容器 | 内容 1200px / 宽版 1280px，两侧留白 ≥ 32px（大屏 48px） |
| 首屏 | 高度 88vh，左侧文案 5 列 / 右侧视觉 7 列（或全幅视频背景） |
| 区块节奏 | 每个区块上下 padding ≥ 96px（移动端 64px） |
| 瀑布流 | 4/3/2/1 列，列间距 24~28px，纵向间距 32px |
| 卡片 | 3:4 为主；标题 15px/600；作者行 13px |
| 断点 | 1280 / 1100 / 760 / 440 |

### 9.6 页面蓝图

**① 首页（门面，不是货架）**
```
[导航：Logo · 灵感 · 画布 · 会员 · 更多▾ ······ 搜索 · 登录/头像]
[首屏 88vh]  左：一句话主张（48~56px，serif 混排）
                  一行副标（15px，最大 480px 宽）
                  [开画]（主按钮·渐变）  [逛逛灵感]（文字按钮）
             右：极光光斑 + 今日精选作品（3 张错落浮动卡）
[信任带]     60+ 模型 · 12 万作品 · 一键同款（数字滚动）
[策展区]     "本周编辑精选" —— 3 张大卡（4:5）+ 一句策展语
[灵感流]     "继续逛" —— 瀑布流首屏 8 张，底部"查看全部"
[分类]       一行 8 个用途 chip（横向可滚），不折叠
[收尾 CTA]   一句话 + 一个按钮，留白 ≥ 120px
[Footer]     四列矩阵（产品/灵感/资源/关于）+ 备案
```

**② 灵感 / Prompt 画廊**
- 顶部：标题 + 计数（"12,480 个灵感"）+ 排序（最新/最热）
- 筛选：**一层**主筛选（全部/文生图/视频/3D）+ "更多筛选"抽屉（行业、模型、风格）
- 主体：瀑布流 4 列（1100px 3 列）
- 卡片：左上无边框标签、封面、标题、作者 + 👁/♥、hover 推挤"生成同款"

**③ 提示词详情 `/prompt-gallery/:id`**
- 左 7 列：大图（可缩放）+ 同作者其他作品
- 右 5 列（sticky）：标题、作者、参数表（模型/尺寸/步数/种子）、提示词块（一键复制）、**生成同款**（唯一主按钮）、相关推荐
- 底部：相似作品横向滚动

**④ 无限画布 `/studio/canvas`**（差异化王牌）
- 全屏、无 chrome；浮层工具栏（左下）、参数抽屉（右侧，默认收起）
- 画布上的每个生成结果都可继续作为输入（节点式但不术语化）

**⑤ 会员**
- 三档卡（免费/专业/团队），一屏放下；权益用"能做什么"表述（可生成 ≈ N 张图）
- 换算表常驻，无倒计时

**⑥ 移动端**
- 底部 tab 四项：首页 / 灵感 / 开画（凸起主按钮）/ 我的
- 首屏高度 72vh，标题 clamp 到 32~36px

### 9.7 与 liblib 的差异化对照

| 维度 | liblib | YMM | 差异来源 |
|---|---|---|---|
| 首屏 | 促销条 + 货架 | 主张 + 精选视觉 | 品牌 vs 促销 |
| 入口数 | 12+ | 4 + 1 | 克制 |
| 主对象 | 模型 | **作品/提示词** | 我们不自研模型 |
| 转化动作 | 去使用 / 做同款 | **生成同款（全局唯一）** | 聚焦 |
| 密度 | 4~5 列，12~16px 间距 | 3~4 列，24~28px 间距 | 呼吸感 |
| 分层 | 1px 边框 | 留白 + 色阶 | 无框 |
| 颜色 | 中性 + 促销红 | 中性 + 单强调渐变 | 品牌记忆 |
| 动效 | 状态过渡 | 首屏/指针/列表三处释放 | 有记忆点 |
| 语气 | 工具、效率 | 画报、灵感 | 年轻潮流 |

### 9.8 设计取舍说明（为什么这么选）

1. **放弃模型货架 → 选作品货架**：模型是"能力"，作品是"欲望"。用户先想要画面，才关心用什么模型；且我们无自研模型，做模型货架会暴露短板。
2. **放弃高密度 → 选大留白**：密度适合"熟手反复使用"，留白适合"新人第一次进入"。我们的增长目标是拉新与分享，首因效应更重要。
3. **放弃多入口 → 选 4+1**：入口越多，路径越短但决策越难；4 个意图（逛/做/管/学）已覆盖 95% 场景。
4. **放弃边框分层 → 选留白分层**：边框在深色模式下会形成"网格噪点"，且与"自由"冲突；留白分层在黑白双方案下都稳定。
5. **放弃满屏动效 → 选三处释放**：动效的价值在"第一次"和"关键动作"，处处动效等于处处不动效。
6. **保留做同款 → 提升为唯一主动作**：这是从"看"到"做"的唯一桥梁，也是我们的转化核心。

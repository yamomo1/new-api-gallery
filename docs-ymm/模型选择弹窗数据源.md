# 「选择模型」弹窗：数据源改为 New API 模型资料

> 2026-11-02 ｜ 前台 `/ai-tool/image-generator`、`/ai-tool/video-generator` 的「选择模型」弹窗

---

## 1. 改了什么

| | 改之前 | 改之后 |
|---|---|---|
| 数据来源 | Fork 自维护的 `GalleryModelCatalog`（Option，后台「画廊预设」里手工填） | **New API 模型资料表**（后台「模型」→ 模型资料的说明/图标/标签） |
| 图标 | 5 个内置图标键（spark/wave/hex/orbit/leaf） | 模型自定义图标（URL / emoji / 图标键）→ 供应商图标 → 默认 |
| 描述 | 手填 | 取模型资料的「说明信息」 |
| 标签 | 手填 | 取模型资料的「标签」（逗号分隔） |
| 分类 | 手填 category | **自动判定**（标签 > 端点类型 > 名称关键词） |
| NEW 角标 | 手填 | 创建时间 30 天内自动加 |

好处：运营在后台「模型」维护一次，前台商品页、价格页、生成器弹窗看到的就一致了，不用两处维护。

## 2. 数据链路

```
后台「模型」表（model 表）
  ├── model_name      模型唯一标识
  ├── description     说明信息
  ├── icon            图标（URL / emoji / 图标键）
  ├── tags            标签（逗号或顿号分隔）
  ├── vendor_id       供应商 → 供应商图标
  └── name_rule       exact / prefix / suffix / contains 匹配规则
        ↓
GET /api/model-catalog  （新增，UserAuth，不含价格）
        ↓
useServerModelCatalog() → 按 category 过滤 → 弹窗卡片
```

### 2.1 为什么新开接口

- `/api/models/` 是 AdminAuth，前台拿不到（且含渠道、价格等敏感信息）；
- `/api/pricing` 有端点类型但**没有**说明、图标、标签；
- 弹窗需要「图标 + 一句话说明 + 能力标签」三样一起，只能新开一条只读接口。

接口返回（每条）：

```json
{
  "model_name": "智能图片V2",
  "category": "image",
  "description": "多参考生成，长文本能力突出，支持超清 4K",
  "icon": "spark",
  "tags": ["图片", "多参考图", "超清4K", "组图模式"],
  "new": true,
  "vendor_name": "",
  "vendor_icon": "",
  "endpoints": ["openai"]
}
```

## 3. 分类规则（三级优先级）

```
1. 标签显式声明：「图片 / image / 图像」→ image；「视频 / video」→ video
2. 端点类型：image_generation → image；openai_video → video
3. 名称关键词：seedream / flux / nano-banana / 图片 / 生图 … → image
                seedance / kling / hailuo / veo / sora / 视频 … → video
都不命中 → text（生成器不展示）
```

**为什么标签优先**：很多站的图片模型挂在 OpenAI 兼容渠道（端点类型是 `openai`），
只靠端点会全部落进 text。给模型打一个「图片」标签就能强制归位，运营可控。

> 本地实测：`智能图片V2` 的端点是 `openai`，打上「图片」标签后正确归到 image。

---

## 4. 图标优先级

```
模型 icon 是 URL（http/https/data:） → <img> 直接渲染
模型 icon 是内置键（spark/wave/hex/orbit/leaf） → 内置样式
模型 icon 是 emoji 或单字 → 原样渲染
否则 → 供应商图标（同上述规则）
否则 → 默认 spark
```

---

## 5. 回退策略

服务端**该分类一条都没有**时，回退到 Fork 自维护的 `GalleryModelCatalog`，并在弹窗顶部显示黄色提示：

> 正在使用站点自定义模型目录。到后台「模型」给模型补上说明、图标与标签后，这里会自动切换。

这样平滑迁移：运营配一个模型就切一个，不会因为没配完而让页面空掉。

---

## 6. 后台怎么配

1. 进 **系统设置 → 模型 → 模型**（或控制台「模型」）；
2. 找到要上架的模型 → 编辑「模型资料」；
3. 填三样：
   - **说明信息**：一句话，弹窗里显示为第二行（超过一行会截断）；
   - **图标**：可填图标 URL、emoji，或留空继承供应商图标；
   - **标签**：输入后按 Enter，建议第一条写分类词（`图片` / `视频`），后面跟能力词（`多参考图`、`超清4K`、`1080p`、`首尾帧`）；
4. 保存。前台弹窗下次拉取（5 分钟缓存）即可看到。

> 注意：只有**同时有可用渠道**的模型才会出现在弹窗里 —— 接口取的是 `/api/pricing` 的可用模型列表，再 join 模型资料。

## 8. 已知限制

1. **展示名就是 model_name**。后台模型资料没有「显示名」字段（图2 也只有一个「模型名称」），
   所以弹窗里显示的是模型标识本身。要显示「智能图片V2」这种友好名，就把渠道里的模型名起成它。
2. **NEW 角标按创建时间算**，不是营销开关。如果想让老模型也带 NEW，只能加一个 `new` 标签（当前不识别）或等后续加字段。
3. **分类没有后台手动控制项**。目前靠标签约定，如果以后要多分类（如「3D」「音频」），建议给 model 表加 `category` 字段而不是继续堆标签。

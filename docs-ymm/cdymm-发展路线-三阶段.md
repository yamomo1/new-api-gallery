# 一幕AI（cdymm.com）三阶段发展路线

> 起点约束：**没有高性能服务器、没有资金、只有一个人 + AI**。
> 核心思路：**先让别人替你算（外链导流赚返利），再用赚到的额度接 API 卖结果，最后才自建算力。**
> 一句话：现金流先于资产，合规先于规模。

---

## 总览

| 阶段 | 时间 | 你卖的是什么 | 谁在付算力费 | 收入来源 | 关键动作 |
|---|---|---|---|---|---|
| **P1 内容 + 外链** | 现在 → 2 个月 | 提示词内容 + 导流 | 访客自己（RunningHub 账号） | 邀请返利（500 RH/人）+ 创作者分成 | 把画廊做厚、把 SEO 做通、把外链铺满 |
| **P2 API 直推** | 2 → 6 个月 | 生成结果（按点数卖） | **你**（RH 币成本） | 点卡差价 / 会员 | 站内直接出图出视频，扣点计费 |
| **P3 自建算力 + 备案** | 6 → 18 个月 | 自有算力 + 合规服务 | 你自己（GPU 折旧） | 订阅 / 席位 / 企业单 | 租卡或托管，跑通备案全链路 |

阶段之间**不是时间到就跳**，而是看退出判据。判据没达到就留在当前阶段继续磨，别提前烧钱。

## P1 · 内容与外链（0 成本阶段）

**目标**：不花一分钱，把「有内容、能被搜到、能导流」这三件事做成。

### 要做的事

1. **内容做厚（不烧算力）**
   - 提示词本身是**文本**，成本≈0。用采集器的「种子导入」批量入库，但**图片先用现成素材/占位**，只对 Top 50 条用 RH 免费额度生成封面。
   - 结构优先级：分类（人像/国风/电商/海报/分镜/产品图）× 风格 × 模型，每条都有中英双语 —— 这是长尾 SEO 的抓手。
   - 目标：**500 条可检索提示词页**（现在先做 100 条跑通收录）。

2. **外链铺满（赚钱的那条线）**
   - 站内所有「去生成」入口一律带推广码 `vuw9qfkj`（已做：`web/src/features/canvas/runninghub.ts` 单一真源）。
   - 位置：画廊详情提示词块、首页 CTA、画布页空状态、页脚。
   - 关键认知：**邀请奖励是拉新一次性 500 RH，不是消费分成**。所以要做「值得注册」的钩子 —— 比如「同款工作流一键复刻」直接落到 RunningHub 对应工作流，转化率远高于落首页。

3. **SEO / GEO 打通（本次已实现）**
   - 服务端注入 title/description/canonical/OG/JSON-LD；`robots.txt` 放行 12 个 AI 爬虫；`sitemap.xml`；`llms.txt`。
   - 后台「二开设置 → SEO 管理」可改全站与逐页文案，**保存即生效，不用重新构建**。
   - 上线后动作见《SEO与GEO落地指南》。

4. **合规：这一段最安全**
   - 只要**不自己对外提供生成服务**（只是导流 + 内容展示），就不构成生成式 AI 服务提供者，无需生成式 AI 备案。
   - 仍需：ICP 备案（站点已在境内）、内容审核（提示词不得含违规描述）、版权（提示词自产或授权，**绝不抓别人社区作品**）。

### 成本与收入

| 项 | 数字 |
|---|---|
| 现金投入 | ≈ 0（域名/服务器你已有） |
| 算力投入 | 0（用 RH 免费额度 + 新号 500 RH） |
| 收入 | 每拉 1 个有效注册 +500 RH（可自用抵扣，也可攒着当 P2 的启动成本） |
| 隐性收益 | 内容资产、索引权重、（可能的）创作者激励分成 |

### 退出判据（三条同时满足才进 P2）

- [ ] 提示词入库 ≥ 500 条，其中 ≥ 100 条有真实生成封面
- [ ] Google/Bing 收录 ≥ 100 页，`site:cdymm.com` 有结果；AI 搜索里搜「一幕AI 提示词」能出现
- [ ] 累计拉新 ≥ 100 人（≈ 5 万 RH 余额），且周活 ≥ 200 UV

> 达到判据意味着：你手里有内容、有流量、有一笔「免费算力」，P2 的试错成本被 P1 覆盖掉了。

## P2 · API 直推（把流量变成收入）

**目标**：用户在你站里输入提示词 → 直接出图/出视频，按「算力点」卖。

### 要做的事

1. **技术链路（已有地基）**
   - 采集器已封装 RunningHub 的提交/轮询/转存：`service/galleryingest/provider_runninghub.go`，改造为「用户请求触发」即可。
   - 必须补：`workflowId` + 提示词 `nodeId` 映射表（每类玩法一条），否则无法注入提示词。
   - 计费：new-api 已有额度内核 + 异步任务框架；把「token 计量」换成「点数/张/秒」（`pkg/billingexpr` 加 times 维度）。
   - 幂等与失败退款：任务超时/失败必须退点，否则投诉率会压死你。

2. **定价模型（务必算清）**
   ```
   售价 = RH 成本 ÷ 汇率 × (1 + 加价率)
   ```
   - RH 币是**你的进货成本**，不是免费资源；P1 攒的余额本质是「预付的算力」。
   - 建议加价率 1.5–2.5×（覆盖失败重试 + 支付手续费 + 退款损耗），先跑 100 单再调。

3. **合规升级（这一步不能省）**
   - 一旦你**品牌化地把生成结果交付给终端用户**，你就是生成式 AI 服务提供者：
     - 《生成式人工智能服务管理暂行办法》→ 服务/算法备案、内容安全机制
     - 《人工智能生成合成内容标识办法》（2025-09-01）→ **显式 + 隐式标识**（本项目 `service/watermark` 已实现，上线即生效）
   - 备案没下来之前：**只做邀请制/海外，不对境内公众开放**，避免裸奔。

### 退出判据

- [ ] 付费转化 ≥ 3%，复购 ≥ 20%
- [ ] 单均毛利 > 0（含失败重试与退款）
- [ ] 月流水覆盖「RH 采购 + 服务器」，且余额能撑 2 个月

## P3 · 自建算力 + 全合规

**目标**：把「进货成本」变成「资产」，毛利从 40% 抬到 70%+。

### 路径（按资金量递进，别一步到位）

1. **租卡托管**（最轻）：租 4090/4090D 整机 → 自建 ComfyUI + 队列 → 只服务付费用户；成本按小时，随时能停。
2. **混合调度**：自有卡跑热门工作流，冷门模型继续走 RH API（成本与稳定性折中）。
3. **自建平台**：new-api 只做记账内核，上层做会员/SKU/workflow 市场（bitahub 那套：网关 + 算力平台分层），别把会员塞进 relay。

### 备案清单（缺一不可）

- [ ] ICP 备案（已有）+ 公安联网备案
- [ ] 生成式 AI 服务备案（网信办）+ 算法备案
- [ ] 内容安全：审核词库 + 人工巡检 + 违规处置留痕
- [ ] 内容标识：显式角标 + 隐式元数据（已实现）
- [ ] 用户协议/隐私政策写明「购买的是服务与结果，非模型 API 访问权」
- [ ] 模型许可逐个核对：**Flux.1-dev 非商用不能卖**，SDXL（OpenRAIL++-M）/Qwen-Image/Flux-schnell（Apache-2.0）可商用

### 退出判据 / 终局判断

- 自建单位成本 < RH 采购价 × 0.7，且高峰并发不排队
- 订阅/席位收入占比 > 50%（比按次卖更稳）

## 三条不要做的事（血泪版）

1. **不要在没备案时对境内公众卖生成结果**——罚款和关停是随时发生的，不是概率问题。
2. **不要买号池/转卖他人 API key**——条款违规 + 刑事风险，和「卖算力」是两件事。
3. **不要为了内容量去抓别人社区作品**——版权 + 平台条款 + 工作流元数据里全是原作者信息，一抓就露。
